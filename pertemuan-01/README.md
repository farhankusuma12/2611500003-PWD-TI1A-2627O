Bukti Belajar P1
Fungsi: dokumentasi capaian pembelajaran P1
1. Konsep Dasar Pemrograman Web
pemrograman web adalah proses membuat halaman web menggunakan/memanfaatkan teknologi pada sisi klien, sisi peladen, serta pengelolaan data.
2. Arsitektur Klien-Peladen
klien sebagai peminta layanan atau sumber daya. sedangkan peladan adalah sebagai penerima permintaan, memproses, dan memberikan respon 
3. HTTP Request dan Response
HTTP Request = permintaan yang dikirim oleh klien kepada peladan  dengan melalui HTTP 
HTTP Response: Balasan atau hasil yang dikirimkan oleh peladen kembali kepada klien setelah permintaan diproses.
4. HTML, CSS, JavaScript, PHP, MySQL
HTML: struktur dasar dan konten halaman web
CSS: mengatur warna, tampilan, dan tata letak
PHP: Bahasa yang memproses logika aplikasi dan data. ini sisi peladen
MySQL: Sistem untuk menyimpan dan mengelola data
5. Hubungan Antarteknologi
HTML, CSS, dan JavaScript bekerja di sisi klient untuk tampilan yang di lihat oleh pengguna. ketika pengguna beraktifitas yang butuh pemrosesan, klien mengirim permintaan ke peladen. Dipeladen, PHP memprose permintaan itu. jika membutuhkan data (misalnya data akun), maka PHP akan mengambil data dari MySQL. setelah selesai, peladen kembali mengirim hasilnya ke klien.
